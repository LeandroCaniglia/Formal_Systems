\chapter{Formal Systems}

\section{Introduction}

A formal system is a deductive environment where mathematical truth is restricted to strict syntactic derivation. It provides a finite alphabet, a grammar for well-formed sentences, a set of axioms, and inference rules to generate new sentences from existing ones.

In Homotopy Type Theory, the most general framework for a deductive environment pairs a type of statements with a dependent family of types representing their provability.

\begin{defn}
    A \textsl{formal system} $\mathcal{F}\colon\fun{System}$ consists of a type of well-formed \textsl{sentences} and a type family of valid \textsl{derivations} for those sentences:
    \[
        \fun{System}\defeq\sum_{S\colon\univ}S\to\univ.
    \]
    The type of valid \textsl{statements} is given by the first projection $\pi_1(\mathcal{F})\colon\univ$. The \textsl{derivation family} is given by the second projection $\pi_2(\mathcal{F})\colon\pi_1(\mathcal F)\to\univ$. 
\end{defn}

This generic type-theoretic definition does not inherently enforce algorithmic structure. To model strictly mechanical systems used in logic (such as Peano Arithmetic), we must instantiate this general architecture with purely syntactic inductive types. 

The statement type $S$ becomes a discrete collection of strings in a given alphabet, and the derivation family $\pi_2(\mathcal{F})$ is built from constructors representing a finite number of deterministic applications of inference rules. This restriction disregards semantic intuition and guarantees the decidability of proof verification.

\section{Peano Arithmetic}
\begin{defn}[Syntax]
    Fix the countably infinite type of variables $\fun{Var}\defeq\N$ with canonical elements $x,y,z,\dots\colon\fun{Var}$.\footnote{This is an implementation choice: all that the metatheory requires of $\fun{Var}$ is decidable equality together with a way to generate a fresh variable outside any finite collection. The name $\fun{Var}$ encapsulates this role as an abstract type of variable names.}
    \begin{enumerate}[a),font=\upshape]
        \item The type of arithmetic \textsl{terms}, denoted $\fun{Term}\colon\univ$, is defined inductively by the following constructors:
        \begin{itemize}
            \item If $x\colon\fun{Var}$, then $\fun{var}(x)\colon\fun{Term}$ (written simply as $x$).
            
            \item The constant $0\colon\fun{Term}$.
            
            \item If $t\colon\fun{Term}$, then $s(t)\colon\fun{Term}$.
            
            \item If $t_1,t_2\colon\fun{Term}$, then $t_1+t_2\colon\fun{Term}$ and $t_1\cdot t_2\colon\fun{Term}$.
        \end{itemize}
        
        \item The type of \textsl{well-formed formulas}, denoted $\fun{Form}\colon\univ$, is defined inductively by the following constructors:
        \begin{itemize}
            \item If $t_1,t_2\colon\fun{Term}$, then $t_1\doteq t_2\colon\fun{Form}$.
            
            \item If $\varphi\colon\fun{Form}$, then $\neg\varphi\colon\fun{Form}$.
            
            \item If $\varphi,\psi\colon\fun{Form}$, then $\varphi\imp\psi\colon\fun{Form}$.
            
            \item If $x\colon\fun{Var}$ and $\varphi\colon\fun{Form}$, then $\forall x\,\varphi\colon\fun{Form}$.
        \end{itemize}
        
        Standard abbreviations are defined as follows:
        \[
            \begin{aligned}
                \varphi\land\psi 
                    &\defeq 
                        \neg(\varphi\imp\neg\psi) \\
                \varphi\lor\psi 
                    &\defeq 
                        \neg\varphi\imp\psi \\
                \varphi\Leftrightarrow\psi 
                    &\defeq 
                        (\varphi\imp\psi) \land (\psi \imp \varphi) \\
                \exists x\,\varphi 
                    &\defeq 
                        \neg\forall x\,\neg\varphi
            \end{aligned}
        \]
    \end{enumerate}
\end{defn}

\begin{rem}
    Semantically, formulas evaluate to truth values and act as logical propositions.
\end{rem}

\begin{rem}\label{rem:Var-equality-facts}
    As proved in \citep{caniglia2025hott} for $\N$, for any variables $x,y\colon\fun{Var}$ the identity type $x\eq{\fun{Var}}y$ is decidable and hence a mere proposition (so $\fun{Var}$ is a set). These properties are used implicitly hereafter.
\end{rem}

\subsection{Structural Induction as Dependent Elimination}

Defining the syntax of Peano Arithmetic via the inductive types $\fun{Term}$ and $\fun{Form}$ automatically equips them with their respective dependent eliminators (or induction principles).

Defining a function or proving a property ``by structural induction'' formally invokes these eliminators.

For terms, let $P\colon\fun{Term}\to\univ$ be a type family. To construct an inhabitant of $\prod_{t\colon\fun{Term}}P(t)$, the dependent eliminator requires providing a proof for each constructor, assuming that the property holds for its sub-components. Formally, we must supply the following dependent functions:
\begin{itemize}
    \item $p_{\fun{var}}\colon\prod_{y\colon\fun{Var}}P(\fun{var}(y))$
    \item $p_0\colon P(0)$
    \item $p_s\colon\prod_{t\colon\fun{Term}}P(t)\to P(s(t))$
    \item $p_+\colon\prod_{t_1,t_2\colon\fun{Term}}P(t_1)\times P(t_2)\to P(t_1+t_2)$
    \item $p_\cdot\colon\prod_{t_1,t_2\colon\fun{Term}}P(t_1)\times P(t_2)\to P(t_1\cdot t_2)$
\end{itemize}
Similarly, for formulas, given a type family $Q\colon\fun{Form}\to\univ$, the dependent eliminator for $\fun{Form}$ requires us to supply:
\begin{itemize}
    \item $q_{\doteq}\colon\prod_{t_1,t_2\colon\fun{Term}}Q(t_1\doteq t_2)$
    \item $q_{\neg}\colon\prod_{\varphi\colon\fun{Form}}Q(\varphi)\to Q(\neg\varphi)$
    \item $q_{\imp}\colon\prod_{\varphi_1,\varphi_2\colon\fun{Form}}Q(\varphi_1)\times Q(\varphi_2)\to Q(\varphi_1\imp\varphi_2)$
    \item $q_{\forall}\colon\prod_{y\colon\fun{Var}}\prod_{\varphi\colon\fun{Form}}Q(\varphi)\to Q(\forall y\,\varphi)$
\end{itemize}
Supplying these inhabitants directly yields the sections $f_P\colon\prod_{t\colon\fun{Term}}P(t)$ and $g_Q\colon\prod_{\varphi\colon\fun{Form}}Q(\varphi)$.

Structural recursion is the specialization of induction when the motive is a constant type family. Given types $A,B\colon\univ$ and $P(t)\equiv A$ and $Q(\varphi)\equiv B$ for all terms and formulas, the dependent products simplify to the ordinary function types $f_A\colon\fun{Term}\to A$ and $g_B\colon\fun{Form}\to B$. Under this non-dependent setting, the induction principle reduces to the recursor. This allows defining computational operations by providing a rule for each constructor based on the recursively computed values of its sub-components. Examples include evaluating a closed term, substituting variables, or extracting the free variables of a formula.

\begin{thm}[Injectivity of Constructors]
    \label{thm:constructor-injectivity}
    The constructors of the freely generated inductive types\/ $\fun{Term}$ and\/ $\fun{Form}$ are injective. For\/ $t,u,t_1,t_2,u_1,u_2\colon\fun{Term}$ and\/ $\varphi_1,\varphi_2,\psi_1,\psi_2\colon\fun{Form}$, the following implications hold:
    \begin{enumerate}[a),font=\upshape]
        \item If\/ $s(t)\eq{\fun{Term}}s(u)$, then\/ $t\eq{\fun{Term}}u$.
        
        \item If\/ $t_1+t_2\eq{\fun{Term}}u_1+u_2$, then\/ $(t_1\eq{\fun{Term}}u_1)\times(t_2\eq{\fun{Term}}u_2)$.
        
        \item Analogous implications hold for all other constructors of arity greater than zero. For instance, if\/ $(\varphi_1\imp\varphi_2)\eq{\fun{Form}}(\psi_1\imp\psi_2)$, then
        \[
            (\varphi_1\eq{\fun{Form}}\psi_1)
            \times
            (\varphi_2\eq{\fun{Form}}\psi_2).
        \]
    \end{enumerate}
\end{thm}

\needspace{2\baselineskip}
\begin{proof}\ 
    \begin{enumerate}[a)]
        \item Define a predecessor function $\fun{pred}\colon\fun{Term}\to\fun{Term}$ by structural recursion:
        \begin{align*}
            \fun{pred}(s(t)) &\defeq t \\
            \fun{pred}(\tau) &\defeq 0 \quad \text{for all other constructors.}
        \end{align*}
        Given $p\colon s(t)\eq{\fun{Term}}s(u)$, applying the functorial action $\fun{ap}_{\fun{pred}}(p)$ yields a path $\fun{pred}(s(t))\eq{\fun{Term}}\fun{pred}(s(u))$, which definitionally reduces to $t\eq{\fun{Term}}u$.
        
        \item Define two projection functions, $\fun{left\_add}$ and $\fun{right\_add}$, from $\fun{Term}$ to $\fun{Term}$:
        \begin{align*}
            \fun{left\_add}(t_1 + t_2) &\defeq t_1 \\
            \fun{left\_add}(\tau) &\defeq 0 \quad \text{for all other constructors,} \\[2mm]
            \fun{right\_add}(t_1 + t_2) &\defeq t_2 \\
            \fun{right\_add}(\tau) &\defeq 0 \quad \text{for all other constructors.}
        \end{align*}
        Given a path $q\colon t_1+t_2\eq{\fun{Term}}u_1+u_2$, $\fun{ap}_{\fun{left\_add}}(q)$ evaluates to $t_1\eq{\fun{Term}}u_1$, and $\fun{ap}_{\fun{right\_add}}(q)$ evaluates to $t_2\eq{\fun{Term}}u_2$. Pairing these paths constructs an inhabitant of the cartesian product $(t_1\eq{\fun{Term}}u_1)\times(t_2\eq{\fun{Term}}u_2)$.
        
        \item As before, define a projection returning the desired sub-component for the specific constructor, and a default value ($0$ for terms or $\fun{var}(0)\doteq\fun{var}(0)$ for formulas) otherwise. Applying $\fun{ap}$ along the assumed path extracts the propositional equality of the sub-components.
    \end{enumerate}
\end{proof}

\begin{thm}[Disjointness of Constructors]
    \label{thm:constructor-disjointness}
    The constructors of the freely generated inductive types\/ $\fun{Term}$ and\/ $\fun{Form}$ are pairwise disjoint. Consequently, paths between terms or formulas built from different constructors cannot exist. For instance, for any variable\/ $x\colon\fun{Var}$ and term\/ $t\colon\fun{Term}$:
    \begin{enumerate}[a),font=\upshape]
        \item $\neg(0\eq{\fun{Term}}s(t))$
        \item $\neg(\fun{var}(x)\eq{\fun{Term}}0)$
    \end{enumerate}
    Analogous inequalities hold for all pairs of distinct constructors in\/ $\fun{Term}$ and\/ $\fun{Form}$.
\end{thm}

\begin{proof} 
    Structural recursion allows defining the following type families:
    \begin{enumerate}[a),font=\upshape]
        \item The type family:
        \begin{align*}
            D\colon\fun{Term}&\to\univ\\
            0&\mapsto\fun1\\
            \tau&\mapsto\fun0\quad
                \text{for all other constructors.}
        \end{align*}
        Suppose we have a proof path $p\colon 0\eq{\fun{Term}}s(t)$. This induces a function $\fun{transport}^D(p)\colon\fun{1}\to\fun{0}$. Thus, we can define the constant map
        \begin{align*}
            \zeta\colon(0\eq{\fun{Term}}s(t))\to\fun0\\
            \lambda q.\,\fun{transport}^D(p,\fstar).
        \end{align*}
        
        \item A similar family
        \begin{align*}
            D\colon\fun{Term}&\to\univ\\
            \fun{var}(y)&\mapsto\fun1
                \quad\text{for all }y\colon\fun{Var}\\
            \tau&\mapsto\fun0
                \quad\text{for all other constructors.}
        \end{align*}
        Assuming a path $p\colon\fun{var}(x)\eq{\fun{Term}}0$, proceed as before using $\fun{transport}^D(p)$ to construct a constant inhabitant of $\neg(\fun{var}(x)\eq{\fun{Term}}0)$. 
    \end{enumerate}
\end{proof}

\begin{lem}[Action on Paths for Binary Functions]
    \label{lem:binap}
    Let\/ $f\colon A\times B\to C$ be a binary function. Given\/ $x_1,x_2\colon A$ and\/ $y_1,y_2\colon B$ with paths\/ $p\colon x_1\eq{A}x_2$ and\/ $q\colon y_1\eq{B}y_2$, there is an induced path
    \[
        \fun{binap}_f(p,q)\colon f(x_1,y_1)\eq{C}f(x_2,y_2).
    \]
\end{lem}

\begin{proof}
    Since
    \begin{align*}
        \fun{ap}_{f(\dummy,y_1)}(p)
            &\colon f(x_1,y_1)\eq Cf(x_2,y_1)
        \quad\text{and}\\
        \fun{ap}_{f(x_2,\dummy)}(q)
            &\colon f(x_2,y_1)\eq Cf(x_2,y_2),
    \end{align*}
    we can define
    \[
        \fun{binap}_f(p,q)\defeq
            \fun{ap}_{f(\dummy,y_1)}(p)
            \ct
            \fun{ap}_{f(x_2,\dummy)}(q).
    \]
\end{proof}

\begin{lem}[Congruence of Constructors]
    \label{lem:constructor-congruence}
    The constructors for terms and formulas respect propositional equality. Given\/ $t_1,t_2,u\colon\fun{Term}$, if\/ $t_1\eq{\fun{Term}}t_2$, then the following identities hold:
    \begin{enumerate}[a),font=\upshape]
        \item $s(t_1)\eq{\fun{Term}}s(t_2)$
        
        \item $(t_1+u)\eq{\fun{Term}}(t_2+u)$ and\/ $(u+t_1)\eq{\fun{Term}}(u+t_2)$
        
        \item $(t_1\doteq u)\eq{\fun{Form}}(t_2\doteq u)$ and\/ $(u\doteq t_1)\eq{\fun{Form}}(u\doteq t_2)$
    \end{enumerate}
    Analogous congruence properties hold for all other constructors in\/ $\fun{Term}$ and\/ $\fun{Form}$.
\end{lem}

\begin{proof}
    The required identities are constructed by applying the action on paths. Fixing the right operand $u$, the application of the equality constructor defines a function
    \begin{align*}
        f_u\colon\fun{Term}&\to\fun{Form}\\
        \tau&\mapsto\tau\doteq u.
    \end{align*}
    Given $p\colon t_1\eq{\fun{Term}}t_2$, we obtain $\fun{ap}_{f_u}(p)\colon(t_1\doteq u)\eq{\fun{Form}}(t_2\doteq u)$.
    
    The proofs for all other cases proceed similarly. For binary constructors like sum or multiplication, apply $\fun{binap}$ to the binary constructor function.
\end{proof}

\begin{thm}\label{thm:syntax-are-sets}
    The inductive types\/ $\fun{Term}$ and\/ $\fun{Form}$ are decidable sets and their identity types are decidable.
\end{thm}

\begin{proof}
    Both types are trivially decidable because they are inhabited.
    
    By Hedberg's Theorem \citep{caniglia2025hott}, to complete the proof, it suffices to show that identity types in $\fun{Term}$ and $\fun{Form}$ are decidable.

    To show that the identity of terms $t\eq{\fun{Term}}u$ is decidable, we proceed by double structural induction.
    \begin{itemize}
        \item When $t\equiv\fun{var}(x)$ and $u\equiv\fun{var}(y)$, the decidability of $x\eq{\fun{Var}}y$ is a direct consequence of the decidability of $\N$. Indeed, if $x\eq{\fun{Var}}y$, the map $\fun{ap}_{\fun{var}}$ yields $t\eq{\fun{Term}}u$. If $\neg(x\eq{\fun{Var}}y)$, Theorem~\ref{thm:constructor-injectivity} gives
        \[
            (\fun{var}(x)\eq{\fun{Term}}\fun{var}(y))
            \to
            (x\eq{\fun{Var}}y),
        \]
        which produces a map
        \[
            \neg(x\eq{\fun{Var}}y)
            \to
            \neg(\fun{var}(x)\eq{\fun{Term}}\fun{var}(y)).
        \]
        
        \item When $t$ and $u$ are built from different constructors, for instance, $t\equiv 0$ and $u\equiv s(u')$, the disjointness of constructors for freely generated inductive types directly provides a proof of $\neg(t\eq{\fun{Term}}u)$.
        
        \item When $t$ and $u$ come from the same composite constructor, for instance, $t\equiv t_1+t_2$ and $u\equiv u_1+u_2$, the inductive hypotheses provide decidability for the sub-components $(t_1, u_1)$ and $(t_2, u_2)$. If $t_1\eq{\fun{Term}}u_1$ and $t_2\eq{\fun{Term}}u_2$ both hold, the action on paths constructs $t\eq{\fun{Term}}u$. If either pair is unequal, the injectivity of the addition constructor implies $\neg(t\eq{\fun{Term}}u)$.
    \end{itemize}
    Since all combinations of constructors are covered, equality on $\fun{Term}$ is decidable. This proves that for any $t,u\colon\fun{Term}$, the identity type $t\eq{\fun{Term}}u$ is a mere proposition. Thus, $\fun{Term}$ is a set.

    Second, we establish the decidability of equality for formulas by constructing a section for
    \[
        \prod_{\varphi,\psi\colon\fun{Form}} (\varphi\eq{\fun{Form}}\psi) + \neg(\varphi\eq{\fun{Form}}\psi).
    \]
    We proceed by double structural induction on $\varphi$ and $\psi$.
    \begin{itemize}
        \item Suppose that $\varphi\equiv t_1\doteq t_2$ and $\psi\equiv u_1\doteq u_2$. Relying on the decidability of equality for terms, there are two cases. If both equalities $t_1\eq{\fun{Term}}u_1$ and $t_2\eq{\fun{Term}}u_2$ hold, the congruence of constructors yields $\varphi\eq{\fun{Form}}\psi$. Otherwise, we may suppose $\neg(t_1\eq{\fun{Term}}u_1)$. By the injectivity of the $\doteq$ constructor, there is a projection $(\varphi\eq{\fun{Form}}\psi)\to(t_1\eq{\fun{Term}}u_1)$. Thus, $\neg(\varphi\eq{\fun{Form}}\psi)$ follows from $\neg(t_1\eq{\fun{Term}}u_1)$.
        
        \item Mismatched constructors (e.g., $\neg\varphi'$ vs $\psi_1\to\psi_2$) are trivially distinct by the disjointness of constructors.
        
        \item For matching propositional connectives ($\neg$ and $\to$), as with composite terms, decidability follows from the inductive hypotheses.
        
        \item For universal quantifiers $\varphi\equiv\forall x\,\varphi'$ and $\psi\equiv\forall y\,\psi'$, we first branch on the decidability of $x\eq{\fun{Var}}y$. If the variables are equal, we evaluate the inductive hypothesis for $\varphi'$ and $\psi'$. If the variables are unequal, or if the subformulas are unequal, then $\neg(\varphi\eq{\fun{Form}}\psi)$ follows from the injectivity of the $\forall$ constructor.
    \end{itemize}
    In conclusion, identities in $\fun{Form}$ are also decidable.
\end{proof}

\section{Free Variables \&\ Substitution}

We begin with a set-theoretic approach to build intuition.

\begin{defn}[Free variables]\label{defn:fv}
    The \textsl{set of free variables of a term}, denoted $\FV(t)$, is defined by induction on the structure of $t\colon\fun{Term}$:
    \begin{itemize}
        \item If $x\colon\fun{Var}$, then $\FV(x)=\set x$.
        \item $\FV(0)=\emptyset$.
        \item $\FV(s(t))=\FV(t)$.
        \item $\FV(t_1+t_2)=\FV(t_1)\cup\FV(t_2)$.
        \item $\FV(t_1\cdot t_2)=\FV(t_1)\cup\FV(t_2)$.
    \end{itemize}
    
    The \textsl{set of free variables of a formula}, denoted $\FV(\varphi)$, is defined by induction on the structure of $\varphi\colon\fun{Form}$:
    \begin{itemize}
        \item $\FV(t_1\doteq t_2)=\FV(t_1)\cup\FV(t_2)$.
        \item $\FV(\neg\varphi)=\FV(\varphi)$.
        \item $\FV(\varphi\imp\psi)=\FV(\varphi)\cup\FV(\psi)$.
        \item $\FV(\forall x\,\varphi)=\FV(\varphi)\setminus\set x$.
    \end{itemize}
\end{defn}

\begin{xmpl}
    The following illustrate the computation of the~$\FV$ operation for various terms and formulas.
    \begin{align*}
    \intertext{Terms:}
        \FV(s(x)+(y\cdot0)) 
            &=\FV(s(x))\cup\FV(y\cdot0)\\
            &=\FV(x)\cup
                \bigl(
                    \FV(y)\cup\FV(0)
                \bigr)\\
            &=\set x\cup(\set y\cup\emptyset)\\
            &=\set{x,y}.
    \intertext{Formulas:}
        \FV(x\doteq s(y)) 
            &=\FV(x)\cup\FV(s(y))\\
            &=\set x\cup\set y\\
            &=\set{x,y}.\\[2mm]
        \FV(\forall y\,(x\doteq y)) 
            &=\FV(x\doteq y)\setminus\set y\\
            &=(\set x\cup\set y)\setminus\set y\\
            &=\set x.\\[2mm]
        \FV\bigl(
            (\forall x\,(x\doteq y))\imp(x\doteq0)
        \bigr)
            &=\FV(\forall x\,(x\doteq y))
                \cup\FV(x\doteq0)\\
            &=\bigl(
                \FV(x\doteq y)\setminus\set x
            \bigr)
                \cup\FV(x\doteq0)\\
            &=\bigl(
                \set{x,y} \setminus\set x
            \bigr)
                \cup\set x\\
            &=\set y\cup\set x\\
            &=\set{x,y}.
    \end{align*}
    In the last formula, the variable $x$ is bound in the antecedent and free in the consequent. The entire formula therefore has $x$ as a free variable because there is at least one unbound occurrence.
\end{xmpl}

\begin{rem}
    Having established the semantics and intuition of free variables, we formally define the concept within homotopy type theory.
\end{rem}

\begin{defn}[Free Variables as Predicates]\label{defn:FV}
    Using the notation of \citep{caniglia2025hott}, the \textsl{free variable maps} $\fun{Term}\to\fun{Pred}(\fun{Var})$ and $\fun{Form}\to\fun{Pred}(\fun{Var})$ assign to each term and formula a predicate indicating whether a given variable has any free occurrence in it.\footnote{Recall that a \textsl{predicate} is a family of mere propositions, i.e., $\fun{Pred}(A)\defeq A\to\fun{Prop}_\univ$.} 

    Both maps are denoted by $\fun{FV}$ and defined by structural recursion. For any $y\colon\fun{Var}$, the proposition $\fun{FV}(t)(y)$ is given by:
    \begin{itemize}
        \item $\fun{FV}(x)(y) \defeq y\eq{\fun{Var}}x$ for any $x\colon\fun{Var}$.
        \item $\fun{FV}(0)(y)\defeq\fun0$.
        \item $\fun{FV}(s(t))(y)\defeq\fun{FV}(t)(y)$.
        \item $\fun{FV}(t_1+t_2)(y)\defeq\lVert\fun{FV}(t_1)(y)+\fun{FV}(t_2)(y)\rVert$.
        \item $\fun{FV}(t_1\cdot t_2)(y)\defeq\lVert\fun{FV}(t_1)(y)+\fun{FV}(t_2)(y)\rVert$.
    \end{itemize}
    Similarly, for any $y\colon\fun{Var}$, the proposition $\fun{FV}(\varphi)(y)$ is given by:
    \begin{itemize}
        \item $\fun{FV}(t_1\doteq t_2)(y)\defeq\lVert\fun{FV}(t_1)(y)+\fun{FV}(t_2)(y)\rVert$.
        \item $\fun{FV}(\neg\varphi)(y)\defeq\fun{FV}(\varphi)(y)$.
        \item $\fun{FV}(\varphi\imp\psi)(y)\defeq\lVert\fun{FV}(\varphi)(y)+\fun{FV}(\psi)(y)\rVert$.
        \item $\fun{FV}(\forall x\,\varphi)(y)\defeq\fun{FV}(\varphi)(y)\times\neg(y\eq{\fun{Var}}x)$.
    \end{itemize}
    Using this formalization, a formula $\varphi\colon\fun{Form}$ is \textsl{closed} if its free-variable predicate is uniformly false. Thus, the condition $\fun{isClosed}\colon\fun{Form}\to\fun{Prop}_\univ$ is defined as the dependent product:
    \[
        \fun{isClosed}(\varphi)\defeq
            \prod_{y\colon\fun{Var}}
                \neg\fun{FV}(\varphi)(y).
    \]
\end{defn}

\begin{prop}\label{prop:FV-is-mere-prop}
    For any term\/ $t\colon\fun{Term}$, formula\/ $\varphi\colon\fun{Form}$, and variable\/ $x\colon\fun{Var}$, the evaluations\/ $\fun{FV}(t)(x)$ and\/ $\fun{FV}(\varphi)(x)$ are mere propositions. Formally, the following types are inhabited:
    \begin{align*}
        &\prod_{t\colon\fun{Term}}\;
        \prod_{x\colon\fun{Var}}
            \fun{isProp}\bigl(\fun{FV}(t)(x)\bigr),\\[2mm]
        &\prod_{\varphi\colon\fun{Form}}\;
        \prod_{x\colon\fun{Var}}
            \fun{isProp}\bigl(\fun{FV}(\varphi)(x)\bigr).
    \end{align*}
\end{prop}

\begin{proof}
    The proof proceeds by structural induction on terms and formulas. Since $\fun{Var}$ is a set, the identity type $x\eq{\fun{Var}}y$ is a mere proposition. Thus, the conclusion holds for the base term $\fun{var}(y)$. It trivially holds for the constant $0$, and the inductive hypothesis shows that it holds for $s(t)$. The cases of term addition and multiplication are trivial because they evaluate to propositionally truncated types.

    For formulas, the conclusion is a direct consequence of the inductive hypotheses and the fact that mere propositions are closed under cartesian products.
    
\end{proof}

\begin{defn}[Variable Occurrence and Fresh Variables]\label{defn:fresh}
    Every variable occurring in a term occurs free, so variable occurrence in terms is already given by $\fun{FV}$ and we can set
    \begin{align*}
        \fun{Occ}\colon\fun{Term}&\to\fun{Pred}(\fun{Var})\\
        \tau&\mapsto\fun{FV}(\tau).
    \end{align*}
    
    For formulas, the \textsl{variable occurrence} predicate
    \[
        \fun{Occ}\colon\fun{Form}\to\fun{Pred}(\fun{Var})
    \]
    (capturing both free and bound occurrences) is defined by structural recursion $\fun{rec}_{\fun{Form}}$ on $\fun{Form}$:
    \begin{itemize}
        \item $\fun{Occ}(\tau_1\doteq\tau_2)(v)\defeq\lVert\fun{FV}(\tau_1)(v)+\fun{FV}(\tau_2)(v)\rVert$.
        \item $\fun{Occ}(\neg\varphi)(v)\defeq\fun{Occ}(\varphi)(v)$.
        \item $\fun{Occ}(\varphi\imp\psi)(v)\defeq\lVert\fun{Occ}(\varphi)(v)+\fun{Occ}(\psi)(v)\rVert$.
        \item $\fun{Occ}(\forall y\,\varphi)(v)\defeq\lVert(y\eq{\fun{Var}}v)+\fun{Occ}(\varphi)(v)\rVert$.
    \end{itemize}
    Using the representation $\fun{Var}\defeq\N$ together with the binary maximum
    \[
        \max\colon\N\to\N\to\N,
    \]
    we define the \textsl{maximum variable index} of a term, 
    \[
        \fun{maxVar}\colon\fun{Term}\to\N,
    \]
    by structural recursion $\fun{rec}_{\fun{Term}}$ on $\fun{Term}$:
    \begin{itemize}
        \item $\fun{maxVar}(\fun{var}(y))\defeq y$.
        \item $\fun{maxVar}(0)\defeq 0$.
        \item $\fun{maxVar}(s(\tau))\defeq\fun{maxVar}(\tau)$.
        \item $\fun{maxVar}(\tau_1+\tau_2)\defeq\max\bigl(\fun{maxVar}(\tau_1),\fun{maxVar}(\tau_2)\bigr)$.
        \item $\fun{maxVar}(\tau_1\cdot\tau_2)\defeq\max\bigl(\fun{maxVar}(\tau_1),\fun{maxVar}(\tau_2)\bigr)$.
    \end{itemize}
    Similarly, 
    \[
        \fun{maxVar}\colon\fun{Form}\to\N,
    \]
    is defined by structural recursion $\fun{rec}_{\fun{Form}}$ on $\fun{Form}$:
    \begin{itemize}
        \item $\fun{maxVar}(\tau_1\doteq\tau_2)\defeq\max\bigl(\fun{maxVar}(\tau_1),\fun{maxVar}(\tau_2)\bigr)$.
        \item $\fun{maxVar}(\neg\varphi)\defeq\fun{maxVar}(\varphi)$.
        \item $\fun{maxVar}(\varphi\imp\psi)\defeq\max\bigl(\fun{maxVar}(\varphi),\fun{maxVar}(\psi)\bigr)$.
        \item $\fun{maxVar}(\forall y\,\varphi)\defeq\max\bigl(y,\fun{maxVar}(\varphi)\bigr)$.
    \end{itemize}
    Finally, the \textsl{fresh variable} function $\fun{fresh}\colon\N\to\fun{Var}$ is defined by
    \[
        \fun{fresh}(b)\defeq\fun{succ}(b).
    \]
\end{defn}

\begin{lem}[Freshness Guarantee]\label{lem:freshness}
    Let\/ $b\colon\N$ and set\/ $z\defeq\fun{fresh}(b)\colon\fun{Var}$.
    \begin{enumerate}[a),font=\upshape]
        \item For every variable\/ $x\colon\fun{Var}$, if\/ $x\le b$, then\/ $\neg(z\eq{\fun{Var}}x)$.

        \item For every term\/ $\tau\colon\fun{Term}$, if\/ $\fun{maxVar}(\tau)\le b$, then\/ $\neg\fun{FV}(\tau)(z)$.

        \item For any $\varphi\colon\fun{Form}$ and $v\colon\fun{Var}$, there is a map $\fun{Occ}(\varphi)(v)\to v\le\fun{maxVar}(\varphi)$.

        \item For any $\varphi\colon\fun{Form}$ and $v\colon\fun{Var}$, there is a map $\fun{FV}(\varphi)(v)\to\fun{Occ}(\varphi)(v)$. 

        \item For every formula\/ $\varphi\colon\fun{Form}$, if\/ $\fun{maxVar}(\varphi)\le b$, then\/ $\neg\fun{Occ}(\varphi)(z)$, and consequently\/ $\neg\fun{FV}(\varphi)(z)$.
    \end{enumerate}
\end{lem}

\begin{proof}
    By definition, $z\equiv\fun{succ}(b)$, so $b<z$.
    \begin{enumerate}[a),font=\upshape]
        \item Suppose $x\le b$ and $p\colon z\eq{\fun{Var}}x$. Combining $x\le b$ with $b<z$ yields a witness $q\colon x<z$. Then
        \[
            \fun{transport}^{u\mapsto(x<u)}(p,\dummy)\colon (x<z)\to(x<x).
        \]
        Applying this map to $q$ gives an element of $x<x$, which is uninhabited.
        \item We first show by induction on $\tau\colon\fun{Term}$ that for all $v\colon\fun{Var}$,
        \begin{equation}\label{eq:maxVar-inequality}
            \tag{$\ast$}
            \fun{FV}(\tau)(v)\to v\le\fun{maxVar}(\tau).
        \end{equation}

        \begin{itemize}
            \item For $\tau\equiv\fun{var}(y)$, we have 
            \[
                \fun{FV}(\fun{var}(y))(v)
                    \equiv(y\eq{\fun{Var}}v)
                \quad\text{and}\quad
                \fun{maxVar}(\fun{var}(y))\equiv y.
            \]
            Thus, given $p\colon y\eq\N v$, the function $\fun{transport}^{u\mapsto(u\le y)}(p,\dummy)$ maps a witness $r\colon y\le y$ to an inhabitant of $v\le y$.

            \item For $\tau\equiv 0$, $\fun{FV}(0)(v)\equiv\fun0$, so $\fun{rec}_{\fun0}(v\le\fun{maxVar}(0))$ is the desired map.

            \item The successor case $s(\tau')$ follows from the induction hypothesis because $\fun{FV}(s(\tau'))\equiv\fun{FV}(\tau')$ and $\fun{maxVar}(\tau')\equiv\fun{maxVar}(s(\tau'))$.

            \item For $\tau_1+\tau_2$, coproduct recursion on $\fun{FV}(\tau_1)(v)+\fun{FV}(\tau_2)(v)$ together with the induction hypotheses gives
            \[
                v\le\fun{maxVar}(\tau_1)
                +
                v\le\fun{maxVar}(\tau_2).
            \]
            In either case
            \[
                v\le\max\bigl(
                    \fun{maxVar}(\tau_1),\fun{maxVar}(\tau_2)
                \bigr)
                \equiv
                \fun{maxVar}(\tau_1+\tau_2). 
            \]
            
            \item The case $\tau_1\cdot\tau_2$ is identical to the sum.
        \end{itemize}

        Now assume $\fun{maxVar}(\tau)\le b$ and $\fun{FV}(\tau)(z)$. The map \eqref{eq:maxVar-inequality} produces a witness of $z\le\fun{maxVar}(\tau)$. Hence, $z\le b$. Combining $b<z$ with $z\le b$ yields $b<b$, which is uninhabited.

        \item We proceed by structural induction on $\varphi$.
        \begin{itemize}
            \item For $\varphi\equiv\tau_1\doteq\tau_2$, coproduct recursion on $\fun{FV}(\tau_1)(v)+\fun{FV}(\tau_2)(v)$ and the map \eqref{eq:maxVar-inequality} from part~b) give
            \[
                v\le\max\bigl(
                    \fun{maxVar}(\tau_1),\fun{maxVar}(\tau_2)
                \bigr)
                \equiv
                \fun{maxVar}(\tau_1\doteq\tau_2).
            \]

            \item The negation and implication cases follow immediately from the induction hypotheses and coproduct recursion for $\imp$.

            \item For $\varphi\equiv\forall y\,\psi$, by Definition~\ref{defn:fresh} we must construct a map
            \[
            \bigl(
                (y\eq{\fun{Var}}v)+\fun{Occ}(\psi)(v)
                \bigr)
                \to
                v\le\max\bigl(y,\fun{maxVar}(\psi)\bigr)
            \]
            from the induction hypothesis $h\colon\fun{Occ}(\psi)(v)\to v\le\fun{maxVar}(\psi)$. Set
            \[
                C\defeq v\le\max\bigl(
                    y,\fun{maxVar}(\psi)
                \bigr).
            \]
            We define two branch maps into $C$:
            \begin{enumerate}[-]
                \item For $f_1\colon(y\eq{\fun{Var}}v)\to C$, given $p\colon y\eq\N v$, transporting a reflexivity witness $r\colon y\le y$ along $p$ gives
                \[
                    \fun{transport}^{u\mapsto u\le y}(p,r)
                        \colon v\le y.
                \]
                Combining $v\le y$ with $y\le\max\bigl(y,\fun{maxVar}(\psi)\bigr)$ yields an inhabitant of $C$.
                
                \item For $f_2\colon\fun{Occ}(\psi)(v)\to C$, the induction hypothesis applied to a witness of $\fun{Occ}(\psi)(v)$ gives $v\le\fun{maxVar}(\psi)$. 
                
                Combining with $\fun{maxVar}(\psi)\le\max\bigl(y,\fun{maxVar}(\psi)\bigr)$ yields an inhabitant of $C$.
            \end{enumerate}
            Coproduct recursion based on $f_1$ and $f_2$ provides the required map.
        \end{itemize}
        
        \item Fix $v\colon\fun{Var}$ and proceed by structural induction on $\varphi\colon\fun{Form}$.
        \begin{itemize}
            \item For $\varphi\equiv\tau_1\doteq\tau_2$, both $\fun{FV}(\tau_1\doteq\tau_2)(v)$ and $\fun{Occ}(\tau_1\doteq\tau_2)(v)$ reduce definitionally to $\lVert\fun{FV}(\tau_1)(v)+\fun{FV}(\tau_2)(v)\rVert$, so the identity map fulfills the requirement.
            
            \item For $\varphi\equiv\neg\psi$, we have 
            \[
                \fun{FV}(\neg\psi)(v)
                    \equiv\fun{FV}(\psi)(v)
                \quad\text{and}\quad
                \fun{Occ}(\neg\psi)(v)
                    \equiv\fun{Occ}(\psi)(v),
            \]
            and the induction hypothesis yields the desired map.
            
            \item For $\varphi\equiv\psi_1\imp\psi_2$, let \begin{align*}
                h_1&\colon\fun{FV}(\psi_1)(v)
                    \to\fun{Occ}(\psi_1)(v)\\
                h_2&\colon\fun{FV}(\psi_2)(v)
                    \to\fun{Occ}(\psi_2)(v)
            \end{align*}
            be the maps provided by the induction hypotheses. Set
            \[
                C\defeq\fun{Occ}(\psi_1\imp\psi_2)(v)
                    \equiv\lVert
                        \fun{Occ}(\psi_1)(v)+\fun{Occ}
                            (\psi_2)(v)
                    \rVert.
            \]
            Coproduct recursion yields a map
            \begin{align*}
                g\colon
                    \fun{FV}(\psi_1)(v)+\fun{FV}(\psi_2)(v)
                    &\to
                    C\\
                u&\mapsto\lvert\fun{inl}(h_1(u))\rvert,\\
                w&\mapsto\lvert\fun{inr}(h_2(w))\rvert.
            \end{align*}
            Since $C$ is a mere proposition, the recursion principle of propositional truncation factors $g$ through a map
            \[
            \lVert\fun{FV}(\psi_1)(v)+\fun{FV}(\psi_2)(v)\rVert\to C
            \]
            of the required type.
            
            \item For $\varphi\equiv\forall y\,\psi$, the induction hypothesis gives a map
            \[
                h\colon\fun{FV}(\psi)(v)
                    \to\fun{Occ}(\psi)(v).
            \]
            Since
            \[
            \fun{FV}(\forall y\,\psi)(v)
                \equiv
                    \fun{FV}(\psi)(v)
                    \times
                    \neg(v\eq{\fun{Var}}y)
            \]
            and
            \[
                \fun{Occ}(\forall y\,\psi)(v)
                    \equiv\lVert
                        (y\eq{\fun{Var}}v)+\fun{Occ}(\psi)(v)
                    \rVert,
            \]
            the required map is given by
            \[
                \lambda x.\,\lvert
                    \fun{inr}(h(\pi_1(x)))
                \rvert
                \colon\fun{FV}(\forall y\,\psi)(v)
                    \to\fun{Occ}(\forall y\,\psi)(v).
            \]
        \end{itemize}

        \item Suppose we are given a witness of $\fun{maxVar}(\varphi)\le b$, and let
        \[
        f\colon\fun{Occ}(\varphi)(z)\to z\le\fun{maxVar}(\varphi)
        \quad\text{and}\quad
        g\colon\fun{FV}(\varphi)(z)\to\fun{Occ}(\varphi)(z)
        \]
        be the maps provided by parts~c) and~d) at $v\equiv z$.
        
        To inhabit $\neg\fun{Occ}(\varphi)(z)$, let $u\colon\fun{Occ}(\varphi)(z)$. Then $f(u)\colon z\le\fun{maxVar}(\varphi)$, which combined with $\fun{maxVar}(\varphi)\le b$ yields a witness of $z\le b$. Since $b<z$, this produces an inhabitant of $b<b$, which is uninhabited. Thus, we have
        \[
            \zeta\colon\fun{Occ}(\varphi)(z)\to\fun0.
        \]
        Composing $\zeta$ with $g$ then yields an inhabitant of $\neg\fun{FV}(\varphi)(z)$.
    \end{enumerate}
\end{proof}

\begin{defns}[Height and Renaming]\label{defn:ht-ren}
    Let
    \begin{align*}
        d_{\fun{Var}}&\colon
            \prod_{u,v\colon\fun{Var}}
                (u\eq{\fun{Var}}v)+\neg(u\eq{\fun{Var}}v)
    \end{align*}
    denote the decidability witness for variable equality.
    \begin{enumerate}[i),font=\upshape]
        \item The \textsl{formula height} function
        \[
            \fun{ht}\colon\fun{Form}\to\N
        \]
        is defined by structural recursion $\fun{rec}_{\fun{Form}}$ on $\fun{Form}$:
        \begin{itemize}
            \item $\fun{ht}(\tau_1\doteq\tau_2)\defeq 0$.
            
            \item $\fun{ht}(\neg\varphi)\defeq\fun{succ}(\fun{ht}(\varphi))$.
            
            \item $\fun{ht}(\varphi\imp\psi)\defeq\fun{succ}\bigl(\max(\fun{ht}(\varphi),\fun{ht}(\psi))\bigr)$.
            
            \item $\fun{ht}(\forall y\,\varphi)\defeq\fun{succ}(\fun{ht}(\varphi))$.
            \end{itemize}
            
            \item Fix $x\colon\fun{Var}$ and $t\colon\fun{Term}$. The \textsl{term substitution} of $t$ for $x$ in a term $\tau\colon\fun{Term}$, denoted $\tau[t/x]\colon\fun{Term}$, is defined by structural recursion $\fun{rec}_{\fun{Term}}$ on $\fun{Term}$:
        \begin{itemize}
        \item
        \[
            \fun{var}(y)[t/x]\defeq
            \begin{cases}
                t
                    &\text{if }x\eq{\fun{Var}}y,\\
                \fun{var}(y)
                    &\text{if }\neg(x\eq{\fun{Var}}y).
            \end{cases}
        \]
        More precisely, setting $E\defeq x\eq{\fun{Var}}y$,
        \[
            \fun{var}(y)[t/x]\defeq\fun{rec}_{E+\neg E}\bigl(
                \fun{Term},
                \lambda e.\,t,
                \lambda\zeta.\,\fun{var}(y),
                d_{\fun{Var}}(x,y)
            \bigr).
        \]
        
        \item $0[t/x]\defeq 0$.
        
        \item $s(\tau)[t/x]\defeq s(\tau[t/x])$.
        
        \item $(\tau_1+\tau_2)[t/x]\defeq\tau_1[t/x]+\tau_2[t/x]$.
        
        \item $(\tau_1\cdot\tau_2)[t/x]\defeq\tau_1[t/x]\cdot\tau_2[t/x]$.
        \end{itemize}
        
        \item Fix $x,z\colon\fun{Var}$. The \textsl{direct variable renaming} map
        \[
            \fun{ren}(\dummy,x,z)\colon
                \fun{Form}\to\fun{Form}
        \]
        is defined by structural recursion $\fun{rec}_{\fun{Form}}$ on $\fun{Form}$:
        \begin{itemize}
            \item $\fun{ren}(\tau_1\doteq\tau_2,x,z)\defeq\tau_1[\fun{var}(z)/x]\doteq\tau_2[\fun{var}(z)/x]$.
            
            \item $\fun{ren}(\neg\varphi,x,z)\defeq\neg\fun{ren}(\varphi,x,z)$.
            
            \item $\fun{ren}(\varphi\imp\psi,x,z)\defeq\fun{ren}(\varphi,x,z)\imp\fun{ren}(\psi,x,z)$.
            
            \item
            \[
                \fun{ren}(\forall y\,\psi,x,z)\defeq
                \begin{cases}
                    \forall y\,\psi
                        &\text{if }x\eq{\fun{Var}}y,\\
                    \forall y\,\fun{ren}(\psi,x,z)
                        &\text{if }\neg(x\eq{\fun{Var}}y).
                \end{cases}
            \]
            More precisely, setting $\varphi\defeq\forall y\,\psi$ and $E\defeq x\eq{\fun{Var}}y$,
            \[
                \fun{ren}(\varphi,x,z)\defeq
                    \fun{rec}_{E+\neg E}\bigl(
                        \fun{Form},
                        \lambda e.\,\varphi,
                        \lambda\zeta.\,\forall y\,\fun{ren}(\psi,x,z),
                        d_{\fun{Var}}(x,y)
                    \bigr).
            \]
        \end{itemize}
    \end{enumerate}
\end{defns}

\begin{lem}\label{lem:ren-preserves-ht}
    For any formula\/ $\varphi\colon\fun{Form}$ and variables\/ $y,z\colon\fun{Var}$, direct variable renaming preserves formula height:
    \[
        \fun{ht}\bigl(
            \fun{ren}(\varphi,y,z)
        \bigr)
        \eq\N
        \fun{ht}(\varphi).
    \]
\end{lem}

\begin{proof}
    Fix $y,z\colon\fun{Var}$ and proceed by structural induction on $\varphi\colon\fun{Form}$.
        \begin{itemize}
        \item \textsc{Case} $\varphi\equiv\tau_1\doteq\tau_2$. By Definition~\ref{defn:ht-ren},
        \begin{align*}
            \fun{ht}(
                \fun{ren}(\tau_1\doteq\tau_2,y,z)
            )
                &\equiv\fun{ht}\bigl(
                    \tau_1[\fun{var}(z)/y]
                    \doteq
                    \tau_2[\fun{var}(z)/y]
                \bigr)\\
                &\equiv0\\
                &\equiv\fun{ht}(\tau_1\doteq\tau_2),
        \end{align*}
        which is witnessed by $\fun{refl}_0$.
        
        \item \textsc{Case} $\varphi\equiv\neg\psi$. Let $p\colon\fun{ht}(\fun{ren}(\psi,y,z))\eq\N\fun{ht}(\psi)$ be the path given by the induction hypothesis. Since
        \[
            \fun{ht}(
                \fun{ren}(\neg\psi,y,z)
            )
            \equiv\fun{succ}\bigl(
                \fun{ht}(\fun{ren}(\psi,y,z))
            \bigr)
            \quad\text{and}\quad
            \fun{ht}(\neg\psi)
            \equiv\fun{succ}(\fun{ht}(\psi)),
        \]
        applying $\fun{ap}_{\fun{succ}}(p)$ yields the required path.
        
        \item \textsc{Case} $\varphi\equiv\psi_1\imp\psi_2$. Let
        \begin{align*}
            p_1&\colon\fun{ht}(\fun{ren}(\psi_1,y,z))
                \eq\N\fun{ht}(\psi_1)
            \text{ and}\\
            p_2&\colon\fun{ht}(\fun{ren}(\psi_2,y,z))
                \eq\N\fun{ht}(\psi_2)
        \end{align*}
        be the paths given by the induction hypotheses. Applying Lemma~\ref{lem:binap} to $\max\colon\N\times\N\to\N$ yields
        \begin{align*}
            \fun{binap}_{\max}(p_1,p_2)\colon
                &\max\bigl(
                    \fun{ht}(\fun{ren}(\psi_1,y,z)),
                    \fun{ht}(\fun{ren}(\psi_2,y,z))
                \bigr)\\
                &\eq\N\\
                &\max\bigl(
                    \fun{ht}(\psi_1),\fun{ht}(\psi_2)
                \bigr).
        \end{align*}
        Applying $\fun{ap}_{\fun{succ}}$ to this path constructs a witness of
        \[
            \fun{ht}(
                \fun{ren}(\psi_1\imp\psi_2,y,z)
            )
            \eq\N
            \fun{ht}(\psi_1\imp\psi_2).
        \]
        
        \item \textsc{Case} $\varphi\equiv\forall w\,\psi$. Let $p\colon\fun{ht}(\fun{ren}(\psi,y,z))\eq\N\fun{ht}(\psi)$ be the induction hypothesis, set $E\defeq y\eq{\fun{Var}}w$, and define the type family $P\colon(E+\neg E)\to\univ$ by
        \[
            P(u)\defeq
                \fun{ht}(
                    \fun{rec}_{E+\neg E}(
                        \fun{Form},
                        \lambda e.\,\forall w\,\psi,
                        \lambda\zeta.\,
                            \forall w\,\fun{ren}(\psi,y,z),u
                    )
                )
                \eq\N
                \fun{ht}(\forall w\,\psi).
        \]
        We construct a section of $P$ by coproduct induction $\fun{ind}_{E+\neg E}$:
        \begin{enumerate}[i)]
            \item For $u\equiv\fun{inl}(e)$ with $e\colon E$, the recursor reduces definitionally to $\forall w\,\psi$, so $P(\fun{inl}(e))$ reduces to $\fun{ht}(\forall w\,\psi)\eq\N\fun{ht}(\forall w\,\psi)$, which is inhabited by $\fun{refl}_{\fun{ht}(\forall w\,\psi)}$.
            
            \item For $u\equiv\fun{inr}(\zeta)$ with $\zeta\colon\neg E$, the recursor reduces definitionally to $\forall w\,\fun{ren}(\psi,y,z)$, so $P(\fun{inr}(\zeta))$ reduces to
            \[
                \fun{succ}\bigl(
                    \fun{ht}(\fun{ren}(\psi,y,z))
                \bigr)
                \eq\N
                \fun{succ}(\fun{ht}(\psi)),
            \]
            which is inhabited by $\fun{ap}_{\fun{succ}}(p)$.
        \end{enumerate}
        Evaluating this section at $d_{\fun{Var}}(y,w)$ gives a path
        \[
            \fun{ht}(
                \fun{ren}(\forall w\,\psi,y,z)
            )
            \eq\N
            \fun{ht}(\forall w\,\psi).
        \]
    \end{itemize}
\end{proof}


\begin{defn}[Substitution]\label{defn:substitution}
    Let
    \begin{align*}
        d_{\fun{FV}}^{\fun{Term}}&\colon
            \prod_{\tau\colon\fun{Term}}\;
            \prod_{v\colon\fun{Var}}
                \fun{FV}(\tau)(v)+\neg\fun{FV}(\tau)(v),\\
        d_{\fun{FV}}^{\fun{Form}}&\colon
            \prod_{\psi\colon\fun{Form}}\;
            \prod_{v\colon\fun{Var}}
                \fun{FV}(\psi)(v)+\neg\fun{FV}(\psi)(v)
    \end{align*}
    denote the decidability witnesses for free-variable membership in terms and formulas.
    
    Fix $x\colon\fun{Var}$ and $t\colon\fun{Term}$. The \textsl{capture-avoiding substitution} of $t$ for $x$ in a formula $\varphi\colon\fun{Form}$, denoted $\varphi[t/x]\colon\fun{Form}$, is defined by strong recursion on $\fun{ht}(\varphi)\colon\N$.
    \begin{itemize}
        \item $(\tau_1\doteq\tau_2)[t/x]\defeq\tau_1[t/x]\doteq\tau_2[t/x]$.
        
        \item $(\neg\varphi)[t/x]\defeq\neg(\varphi[t/x])$.
        
        \item $(\varphi\imp\psi)[t/x]\defeq\varphi[t/x]\imp\psi[t/x]$.
        
        \item Setting
        \[
            m\defeq\max\bigl(
                x,
                \fun{maxVar}(t),
                \fun{maxVar}(\forall y\,\varphi)
            \bigr)
            \quad\text{and}\quad
            z\defeq\fun{fresh}(m),
        \]
        \[
            (\forall y\,\varphi)[t/x]\defeq
            \begin{cases}
                \forall y\,\varphi
                    &\text{if }\neg\fun{FV}(
                        \forall y\,\varphi
                    )(x),\\
                \forall y\,(\varphi[t/x])
                    &\text{if }\fun{FV}(
                        \forall y\,\varphi
                    )(x)
                    \times
                    \neg\fun{FV}(t)(y),\\
                \forall z\,\bigl(
                    \fun{ren}(\varphi,y,z)[t/x]
                \bigr)
                    &\text{if }\fun{FV}(
                        \forall y\,\varphi
                    )(x)
                    \times\fun{FV}(t)(y).
            \end{cases}
        \]
        More precisely, with $P\defeq\fun{FV}(\forall y\,\varphi)(x)$ and $Q\defeq\fun{FV}(t)(y)$,
        \[
            (\forall y\,\varphi)[t/x]
            \defeq
            \fun{rec}_{P+\neg P}\bigl(
                \fun{Form},
                \lambda p.\,b,
                \lambda\zeta.\,\forall y\,\varphi,
                d_{\fun{FV}}^{\fun{Form}}(
                    \forall y\,\varphi,x
                )
            \bigr),
        \]
        where
        \begin{align*}
            b\defeq\fun{rec}_{Q+\neg Q}\bigl(
                &\fun{Form},\\
                &\lambda q.\,\forall z\,\bigl(
                    \fun{ren}(\varphi,y,z)[t/x]
                \bigr),\\
                &\lambda\zeta.\,\forall y\,(
                    \varphi[t/x]
                ),\\
                &d_{\fun{FV}}^{\fun{Term}}(t,y)
            \bigr).
        \end{align*}
    \end{itemize}
\end{defn}        


\begin{rem}\label{rem:substitution-strong-recursion}
    In the capturing branch of Definition~\ref{defn:substitution} for $(\forall y\,\varphi)[t/x]$, where both $\fun{FV}(\forall y\,\varphi)(x)$ and $\fun{FV}(t)(y)$ hold, substitution is applied to the renamed formula $\fun{ren}(\varphi,y,z)$. Because $\fun{ren}(\varphi,y,z)$ is a newly constructed formula rather than an immediate syntactic subformula of $\forall y\,\varphi$, capture-avoiding substitution cannot be defined directly by plain structural recursion on $\fun{Form}$, which supplies recursively computed values only for immediate subformulas.
    
    To overcome this obstacle, Definition~\ref{defn:substitution} proceeds by strong recursion on the natural number $n\defeq\fun{ht}(\phi)$. At stage $n\colon\N$, the recursion hypothesis provides substitution for every formula $\chi\colon\fun{Form}$ satisfying $\fun{ht}(\chi)<n$. Consequently, whenever the clause for a formula $\phi$ invokes a recursive call on a formula $\chi$, a witness of the strict inequality $\fun{ht}(\chi)<\fun{ht}(\phi)$ is required. There are two cases:
    \begin{itemize}
        \item The atomic clause $\tau_1\doteq\tau_2$ makes no recursive call on formulas. For $\neg\varphi$, $\varphi\imp\psi$, and the non-capturing branch of $\forall y\,\varphi$, the defining equations of $\fun{ht}$ in Definitions~\ref{defn:ht-ren} directly yield
        \[
            \fun{ht}(\varphi)
            <
            \fun{ht}(\neg\varphi),
            \quad
            \fun{ht}(\varphi),\fun{ht}(\psi)
            <
            \fun{ht}(\varphi\imp\psi),
            \quad
            \fun{ht}(\varphi)
            <
            \fun{ht}(\forall y\,\varphi).
        \]
        
        \item In the capturing branch of $\forall y\,\varphi$, the non-structural call on $\fun{ren}(\varphi,y,z)$ requires a witness of $\fun{ht}\bigl(\fun{ren}(\varphi,y,z)\bigr)<\fun{ht}(\forall y\,\varphi)$. Lemma~\ref{lem:ren-preserves-ht} supplies a path
        \[
            p\colon\fun{ht}\bigl(
            \fun{ren}(\varphi,y,z)
            \bigr)
            \eq\N
            \fun{ht}(\varphi).
        \]
        Transporting an inhabitant $q\colon\fun{ht}(\varphi)<\fun{ht}(\forall y\,\varphi)\equiv\fun{succ}(\fun{ht}(\varphi))$) along $p^{-1}$ yields the required witness:
        \[
            \fun{transport}^{
                k\,\mapsto k\,<\,\fun{ht}(\forall y\,\varphi)
            }(p^{-1},q)
            \colon
                \fun{ht}(\fun{ren}(\varphi,y,z))
                <
                \fun{ht}(\forall y\,\varphi).
        \]
    \end{itemize}
\end{rem}

\begin{xmpl}
    The following examples illustrate the behavior of capture-avoiding substitution in universally quantified formulas.

    \begin{description}[font=\normalfont\scshape]
        \item[Case 1: $x\eq{\fun{Var}}y$.]
        \[
            (\forall x\,(x\doteq z))[s(0)/x]
                \equiv\forall x\,(x\doteq z).
        \]
        
        \item[Case 2: $\neg(x\eq{\fun{Var}}y)$ and $\neg\fun{FV}(t)(y)$.]
        \[
            (\forall y\,(x\doteq y))[s(z)/x]
                \equiv\forall y\,(s(z)\doteq y).
        \]
        
        \item[Case 3: $\neg(x\eq{\fun{Var}}y)$ and $\fun{FV}(t)(y)$.] Consider
        \[
            (\forall y\,(\explain[\varphi]{x\doteq y}))[\explain[t]{y+s(0)/x}].
        \]
        First note that for any variable $v\colon\fun{Var}$, we have the following equalities in $\fun{Prop}_\univ$:
        \begin{align*}
            \fun{FV}(y+s(0))(v)
                &\equiv\lVert\fun{FV}(y)(v)+\fun{FV}(s(0))(v)\rVert\\
                &\equiv\lVert\fun{FV}(y)(v)+\fun{FV}(0)(v)\rVert\\
                &\equiv\lVert\fun{FV}(y)(v)+\fun0\rVert\\
                &\eq{\fun{Prop}_\univ}\fun{FV}(y)(v)\\
                &\equiv(v\eq{\fun{Var}}y).
        \end{align*}
        Consequently, evaluating this at $v\equiv y$ yields
        \[
            \fun{FV}(y+s(0))(y)
                \eq{\fun{Prop}_\univ}
                (y\eq{\fun{Var}}y),
        \]
        which is inhabited by $\fun{refl}_y$. Therefore, if we were to blindly substitute $x$ with $y+s(0)$, the free variable $y$ would be captured, i.e., it would become bound.

        \needspace{2\baselineskip}
        The definition tells us to proceed as follows:
        \begin{enumerate}[1)]
            \item Pick a fresh variable $z$ not present in the expressions, i.e., so that $\neg(z\eq{\fun{Var}}x)$ and $\neg\lVert\fun{FV}(t)(z)+\fun{FV}(\varphi)(z)\rVert$.
            \item Rename the bound variable inside the subformula $\varphi$:
            \[
                (x\doteq y)[z/y]\equiv x\doteq z.
            \]
            \item Perform the original substitution on the renamed subformula:
            \[
                (x\doteq z)[y+s(0)/x]
                    \equiv(y+s(0)\doteq z).
            \]
            \item Bind the fresh variable:
            \[
                \forall z\,(y+s(0)\doteq z).
            \]
        \end{enumerate}
        Thus, we obtain:
        \[
            (\forall y\,(x\doteq y))[y+s(0)/x]
                \equiv\forall z\,(y+s(0)\doteq z).
        \]
        Note how the free $y$ in the term $y+s(0)$ remains free.
    \end{description}
\end{xmpl}

\begin{defn}\label{defn:free-for-in}
    Let $t\colon\fun{Term}$, $x\colon\fun{Var}$, and $\varphi\colon\fun{Form}$. We say $t$ is \textsl{free for $x$ in $\varphi$} (or \textsl{substitutable for $x$ in $\varphi$}) if substituting $t$ for the free occurrences of $x$ in $\varphi$ does not result in any free variable of $t$ becoming bound. Formally, this establishes a predicate $\fun{isFreeFor}(t,x,\varphi)\colon\fun{Prop}_\univ$ by structural induction on $\varphi$:
    \begin{align*}
        &\fun{isFreeFor}(t,x,\tau_1\doteq\tau_2)
            \defeq\fun1\\
        &\fun{isFreeFor}(t,x,\neg\psi)
            \defeq\fun{isFreeFor}(t,x,\psi)\\
        &\fun{isFreeFor}(t,x,\psi_1\imp\psi_2)
            \defeq\fun{isFreeFor}(t,x,\psi_1)
            \times
            \fun{isFreeFor}(t,x,\psi_2)\\
        &\fun{isFreeFor}(t,x,\forall y\,\psi)
            \defeq\big\lVert(x\eq{}y)
            +
            \bigl(
                \neg(x\eq{}y)\times\neg\fun{FV}(t)(y)
                \times
                \fun{isFreeFor}(t,x,\psi)
            \bigr)\big\rVert.
    \end{align*}
\end{defn}

\begin{rem}
    A term $t$ is free for a variable $x$ in a formula $\varphi$ if replacing the free occurrences of $x$ in $\varphi$ with $t$ does not cause any free variable of $t$ to become bound by a quantifier in $\varphi$.
    
    Consider the formula $\varphi \equiv \forall y\,\neg(x \doteq y)$, where $x$ is free and $y$ is bound. If we define the term $t \defeq s(y)$, then $y$ is free in $t$. Substituting $t$ for $x$ without restriction yields
    \[
        \varphi[t/x] \equiv \forall y\,\neg(s(y) \doteq y).
    \]
    The variable $y$, originally free in $t$, is now captured by the $\forall y$ quantifier. Consequently, the term $s(y)$ is not free for $x$ in $\varphi$.
    
    Conversely, the term $s(z)$ is free for $x$ in $\varphi$. The substitution evaluates to $\forall y\,\neg(s(z) \doteq y)$, which preserves the freedom of~$z$.
\end{rem}

\begin{lem}[Substitution Preserves Equality]\label{lem:subst-equality}
    Let\/ $x,y\colon\fun{Var}$, $t,u\colon\fun{Term}$, and\/ $\varphi,\psi\colon\fun{Form}$. The substitution operation preserves propositional equality across all its arguments:
    \begin{enumerate}[a),font=\upshape]
        \item If\/ $\varphi\eq{\fun{Form}}\psi$, then\/ $\varphi[t/x]\eq{\fun{Form}}\psi[t/x]$.
        \item If\/ $t\eq{\fun{Term}}u$, then\/ $\varphi[t/x]\eq{\fun{Form}}\varphi[u/x]$.
        \item If\/ $x\eq{\fun{Var}}y$, then\/ $\varphi[t/x]\eq{\fun{Form}}\varphi[t/y]$.
    \end{enumerate}
    Analogous properties hold for term substitutions\/ $\tau[t/x]$.
\end{lem}

\begin{proof}
    Define the function 
    \begin{align*}
        \fun{subst}\colon
            \fun{Form}\times\fun{Term}\times\fun{Var}
                &\to\fun{Form}\\
            (\varphi,t,x)&\mapsto\varphi[t/x].
    \end{align*}
    Since every function respects propositional equality via the action on paths, applying path induction to any of the three arguments induces a path in the codomain. For instance, given $p\colon t\eq{\fun{Term}}u$, the functorial action of the substitution function yields the path
    \[
        \fun{ap}_{\fun{subst}(\varphi,\dummy,x)}(p)
            \colon\varphi[t/x]\eq{\fun{Form}}\varphi[u/x].
    \]
    Cases a) and c) follow similarly. 
\end{proof}

\begin{lem}[Term Substitution Properties]\label{lem:term-substitution}
    Let\/ $x,y\colon\fun{Var}$ and\/ $\tau,t,u\colon\fun{Term}$. Term substitution satisfies the following properties:
    \begin{enumerate}[a),font=\upshape]
        \item $\tau[x/x]\eq{\fun{Term}}\tau$.

        \item If\/ $\neg\fun{FV}(\tau)(x)$, then\/ $\tau[t/x]\eq{\fun{Term}}\tau$.

        \item If\/ $\neg(x\eq{\fun{Var}}y)$ and\/ $\neg\fun{FV}(u)(x)$, then\/ $\tau[t/x][u/y]\eq{\fun{Term}}\tau[u/y][t[u/y]/x]$.
    \end{enumerate}
\end{lem}

\begin{proof}
    Each part is proved by induction on $\tau\colon\fun{Term}$. In all three parts, the constant case $\tau\equiv 0$ holds by reflexivity, and the inductive steps for $s(\tau')$, $\tau_1+\tau_2$, and $\tau_1\cdot \tau_2$ follow directly from the induction hypotheses by congruence ($\fun{ap}$), noting for part~b) that $\neg\fun{FV}(\tau_1+\tau_2)(x)$ (and likewise for multiplication) implies both $\neg\fun{FV}(\tau_1)(x)$ and $\neg\fun{FV}(\tau_2)(x)$. It therefore suffices to check the variable case $\tau\equiv v$ for $v\colon\fun{Var}$.
    \begin{enumerate}[a),font=\upshape]
        \item By decidability of equality on $\fun{Var}$, either $v\eq{\fun{Var}}x$ or $\neg(v\eq{\fun{Var}}x)$. In the first case, $v[x/x]\equiv x$, which equals $v$ by symmetry of $v\eq{\fun{Var}}x$; in the second, $v[x/x]\equiv v$ by definition.

        \item The hypothesis $\neg\fun{FV}(v)(x)$ means $\neg(v\eq{\fun{Var}}x)$, so $v[t/x]\equiv v$.

        \item We split by decidability of $v\eq{\fun{Var}}x$ and $v\eq{\fun{Var}}y$:
        \begin{itemize}
            \item If $v\eq{\fun{Var}}x$, then $\neg(v\eq{\fun{Var}}y)$ since $\neg(x\eq{\fun{Var}}y)$. Hence
            \[
                v[t/x][u/y]\equiv t[u/y]\equiv v[t[u/y]/x]\equiv v[u/y][t[u/y]/x].
            \]
            \item If $v\eq{\fun{Var}}y$, then $\neg(v\eq{\fun{Var}}x)$ since $\neg(x\eq{\fun{Var}}y)$. Thus
            \[
                v[t/x][u/y]\equiv v[u/y]\equiv u,
            \]
            while
            \[
                v[u/y][t[u/y]/x]\equiv u[t[u/y]/x].
            \]
            Since $\neg\fun{FV}(u)(x)$, part~b) gives $u[t[u/y]/x]\eq{\fun{Term}}u$.
            \item If $\neg(v\eq{\fun{Var}}x)$ and $\neg(v\eq{\fun{Var}}y)$, then both sides reduce to $v$.
        \end{itemize}
    \end{enumerate}
\end{proof}

\begin{prop}\label{prop:substitution-properties}
    Let\/ $x,y\colon\fun{Var}$, $t,u\colon\fun{Term}$, and\/ $\varphi\colon\fun{Form}$. Substitution satisfies the following properties:
    \begin{enumerate}[a),font=\upshape]
        \item $\varphi[x/x]\eq{\fun{Form}}\varphi$.
        
        \item If\/ $\neg\fun{FV}(\varphi)(x)$, then\/ $\varphi[t/x]\eq{\fun{Form}}\varphi$.
        
        \item If\/ $\neg(x\eq{\fun{Var}}y)$ and\/ $\neg\fun{FV}(u)(x)$, then\/ $\varphi[t/x][u/y]\eq{\fun{Form}}\varphi[u/y][t[u/y]/x]$.
    \end{enumerate}
    Analogous properties hold for term substitutions.
\end{prop}

\begin{proof} 
    In all three cases, we proceed by structural induction on $\varphi$. 
    \begin{enumerate}[a),font=\upshape]
        \item 
        \begin{itemize}
            \item If $\varphi\equiv\tau_1\doteq\tau_2$, then $(\tau_1\doteq \tau_2)[x/x]\equiv \tau_1[x/x]\doteq \tau_2[x/x]$. By Lemma~\ref{lem:term-substitution}, this is $\tau_1\doteq\tau_2$.
            
            \item For the propositional connectives, the definition of substitution distributes the operation directly over the subformulas. We illustrate this with the implication $\varphi \equiv\psi_1\imp\psi_2$. By definition
            \[
                \neg\fun{FV}(\psi_1\imp\psi_2)(x)
                \equiv
                \neg\lVert
                    \fun{FV}(\psi_1)(x)
                    +
                    \fun{FV}(\psi_2)(x)
                \rVert,
            \]
            which logically implies both $\neg\fun{FV}(\psi_1)(x)$ and $\neg\fun{FV}(\psi_2)(x)$. The result follows by distributing the substitution:
            \begin{align*}
                (\psi_1\imp \psi_2)[x/x] 
                    &\equiv \psi_1[x/x]\imp\psi_2[x/x] \\
                    &\eq{\fun{Form}}\psi_1\imp\psi_2 
                        &&\text{; IH}
            \end{align*}
            The case of negation, $\varphi\equiv\neg\psi$, follows the same logic.
            
            \item If $\varphi\equiv\forall y\,\psi$, there are two cases:
            \begin{enumerate}[i)]
                \item If $x\eq{\fun{Var}}y$, then by definition $(\forall x\,\psi)[x/x]\equiv\forall x\,\psi$.
                
                \item If $\neg(x\eq{\fun{Var}}y)$, then since $\fun{FV}(x)(y)\equiv y\eq{\fun{Var}}x$, which is false, we get $(\forall y\,\psi)[x/x]\equiv\forall y\,(\psi[x/x])$. By the inductive hypothesis, this is propositionally equal to $\forall y\,\psi$.
            \end{enumerate}
        \end{itemize}
        
        \item 
        \begin{itemize}
            \item If $\varphi\equiv \tau_1\doteq \tau_2$, then $\neg\fun{FV}(\tau_1\doteq \tau_2)(x)$ implies both $\neg\fun{FV}(\tau_1)(x)$ and $\neg\fun{FV}(\tau_2)(x)$. The conclusion follows by the induction hypothesis.
            
            \item The propositional connective cases follow directly from the induction hypothesis.
            
            \item Suppose $\varphi\equiv\forall y\,\psi$. By the decidability of $\fun{Var}$ there are two possibilities:
            
            $-$ If $x\eq{\fun{Var}}y$, the substitution of $t$ for $x$ returns $\varphi$, as stated.
            
            $-$ If $\neg(x\eq{\fun{Var}}y)$, we may assume without loss of generality that the bound variable $y$ satisfies $\neg\fun{FV}(t)(y)$. Then the substitution yields $\forall y\,(\psi[t/x])$. Since Definition~\ref{defn:FV} establishes the identity
            \[
                \fun{FV}(\forall y\,\psi)(x)
                \equiv
                \fun{FV}(\psi)(x)
                \times
                \neg(x\eq{\fun{Var}}y),
            \]
            and we have $\neg\fun{FV}(\forall y\,\psi)(x)$ by hypothesis, we deduce $\neg\fun{FV}(\psi)(x)$. Thus, the inductive hypothesis implies $\psi[t/x]\eq{\fun{Form}}\psi$, and so the substitution in $\varphi$ reduces to $\forall y\,\psi$.
        \end{itemize}
        
        \item
        \begin{itemize}
            \item For terms, the base case $\fun{var}(v)$ has three subcases:
            \begin{enumerate}[i)]
                \item Case $v\eq{\fun{Var}}x$: Since we have the premise $\neg(x\eq{\fun{Var}}y)$, this case also implies $\neg(v\eq{\fun{Var}}y)$.
                \begin{align*}
                    \lhs&\equiv v[t/x][u/y]\\
                        &\eq{\fun{Term}}x[t/x][u/y]
                            &&;\ \text{Lem.~\ref{lem:subst-equality}}\\
                        &\equiv t[u/y].\\[2mm]
                    \rhs&\equiv v[u/y][t[u/y]/x]\\
                        &\eq{\fun{Term}} v[t[u/y]/x]
                            &&;\ \neg(v\eq{\fun{Var}}y)\\
                        &\eq{\fun{Term}} t[u/y]
                            &&;\ v\eq{\fun{Var}}x.
                \end{align*}
                
                \item Case $v\eq{\fun{Var}}y$:
                \begin{align*}
                    \lhs&\equiv v[t/x][u/y]\\
                        &\eq{\fun{Term}}y[t/x][u/y]
                            &&;\ \text{Lem.~\ref{lem:subst-equality}}\\
                        &\equiv y[u/y]
                            &&;\ \neg(x\eq{\fun{Var}}y)\\
                        &\equiv u.\\[2mm]
                    \rhs&\equiv v[u/y][t[u/y]/x]\\
                        &\eq{\fun{Term}}y[u/y][t[u/y]/x]
                            &&;\ \text{Lem.~\ref{lem:subst-equality}}\\
                        &\equiv u[t[u/y]/x]\\
                        &\eq{\fun{Term}} u
                            &&;\ \text{part b), since } \neg\fun{FV}(u)(x).
                \end{align*}
                
                \item Case $\neg(v\eq{\fun{Var}}x)$ and $\neg(v\eq{\fun{Var}}y)$: 
                \begin{align*}
                    \lhs&\equiv v[t/x][u/y]\\
                        &\eq{\fun{Term}} v[u/y]
                            &&;\ \neg(v\eq{\fun{Var}}x)\\
                        &\eq{\fun{Term}} v
                            &&;\ \neg(v\eq{\fun{Var}}y).\\[2mm]
                    \rhs&\equiv v[u/y][t[u/y]/x]\\
                        &\eq{\fun{Term}} v[t[u/y]/x]
                            &&;\ \neg(v\eq{\fun{Var}}y)\\
                        &\eq{\fun{Term}} v
                            &&;\ \neg(v\eq{\fun{Var}}x).
                \end{align*}
            \end{enumerate}
            
            \item For composite terms and propositional connectives, the substitution operations distribute directly over the constructors. In the case of term addition, we have
            \begin{align*}
                (\tau_1+\tau_2)[t/x][u/y]
                    &\equiv
                        (\tau_1[t/x]+\tau_2[t/x])[u/y]\\
                    &\equiv
                        \tau_1[t/x][u/y]+\tau_2[t/x][u/y] \\
                    &\eq{\fun{Term}}
                        \tau_1[u/y][t[u/y]/x]
                        +\tau_2[u/y][t[u/y]/x]
                        &&\text{; IH}\\
                    &\equiv
                        (
                            \tau_1[u/y]+\tau_2[u/y]
                        )
                        [t[u/y]/x] \\
                    &\equiv
                        (\tau_1+\tau_2)[u/y][t[u/y]/x].
            \end{align*}
            The same argument applies to multiplication, atomic equalities, and the propositional connectives (e.g., $\varphi \equiv \psi_1 \imp \psi_2$).
            
            \item If $\varphi\equiv\forall z\,\psi$, we can assume that the bound variable $z$ satisfies $\neg(z\eq{\fun{Var}}x)$ and $\neg(z\eq{\fun{Var}}y)$, as well as $\neg\fun{FV}(t)(z)$ and $\neg\fun{FV}(u)(z)$. Therefore, neither substitution modifies or is captured by $z$. The operations distribute inside the quantifier:
            \begin{align*}
                (\forall z\,\psi)[t/x][u/y]
                    &\equiv\forall z\,(\psi[t/x][u/y])\\
                    &\eq{\fun{Form}}\forall z\,(\psi[u/y][t[u/y]/x])
                        &&\text{; IH}\\
                    &\equiv(\forall z\,\psi)[u/y][t[u/y]/x].
            \end{align*}\qedhere
        \end{itemize}
    \end{enumerate}
\end{proof}
